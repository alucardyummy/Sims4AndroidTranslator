1. O que é isso?

Imagina o site como uma casa. O CSS é a tinta e o pincel: ele não muda onde ficam as portas, só a cor das paredes, o tamanho dos móveis e esse tipo de coisa. Ou seja: você só muda a aparência, não tem como estragar o site.

O que você escreve vale só pra você (ninguém mais vê) e funciona em todas as telas e em todos os aparelhos em que você entrar na sua conta.

2. Onde eu colo?

  1. Entre na sua conta (o CSS personalizado só aparece pra quem está logado).
  2. Na home, toque na bolinha do perfil (canto de cima).
  3. Abra a seção “CSS personalizado” e cole o seu CSS na caixa.
  4. Aplicar = só uma prévia, pra espiar. Se recarregar a página, ela some.
  5. Salvar CSS = guarda de verdade. Apareceu “CSS salvo!”? Pronto.
  6. Copiar copia o texto. Restaurar padrão apaga tudo e o site volta ao normal.
Importante: Aplicar não é Salvar! Gostou do resultado? Aperte Salvar CSS, senão ele some quando você recarregar.
Máximo de 20.000 caracteres (a caixa mostra a contagem). E cole só CSS de gente em quem você confia.

3. Como o CSS é escrito

Todo pedacinho de CSS é uma frase assim:

QUEM {
  O QUE MUDAR: COMO;
}

Tipo: “o botão grande { cor do texto: rosa; }”. Na linguagem do site:

.btn-new {
  color: hotpink;
}

Dá pra mudar várias coisas de uma vez, uma por linha, e sempre terminando com ponto e vírgula ; (esquecer ele é o erro mais comum!). Tudo que fica entre /* e */ é comentário: o site ignora, é só um bilhetinho seu.

As propriedades mais usadas

color
cor do texto
background
cor (ou degradê, ou imagem) do fundo
border
a bordinha. Ex.: 1px solid pink (grossura, tipo, cor)
border-radius
quão redondo são os cantos. 0 = quadrado, 999px = pílula
font-size
tamanho da letra. Ex.: 18px
font-family
o tipo de letra. Ex.: Georgia, serif
opacity
transparência: 1 normal, 0.5 meio apagado, 0 invisível
display: none
esconde a coisa (como se ela nunca tivesse existido)
padding e margin
espaço por dentro e por fora da coisa

4. Cores

Dá pra escrever a cor de três jeitos (todos funcionam em qualquer lugar):

Por nome
red, hotpink, gold, teal…
Por código
#ff4fa3. Pesquise “seletor de cor” no Google, escolha a cor e copie o código.
Com transparência
rgba(255, 79, 163, 0.3): os três primeiros são vermelho, verde e azul (0 a 255); o último é a transparência (0 a 1).

Degradê (duas cores se misturando): background: linear-gradient(135deg, #ff4fa3, #35e0ff);

5. Variáveis mágicas (o jeito mais fácil!)

O site tem uns “botões de cor” escondidos chamados variáveis. Mudou uma, mudou o site inteiro de uma vez. É o truque mais poderoso, então comece por aqui:

:root {
  --accent: #ff4fa3;
}

Isso troca a cor de destaque em todas as telas. As variáveis são:

--bg
cor de fundo das telas
--surface
fundo de cartões, caixas e botões
--surface2
fundo de caixas mais “fundas” (campos, linhas)
--surface3
fundo de áreas extras (tela Criar)
--border, --border2, --border3
cores das bordinhas (da mais fraca à mais forte)
--accent
cor de destaque: títulos, ícones, números, links
--accent-dim
destaque mais escuro (botões, quando você aperta)
--accent-faint
destaque bem clarinho (fundos suaves)
--text
cor do texto principal
--text-muted
cor do texto de apoio (as letrinhas menores)
--text-dim
cor do texto bem discreto
--danger
vermelho de erro e de apagar
--radius, --radius-sm, --radius-xs
quão redondos são os cantos (grande, médio, pequeno)
--font-title, --font-body, --font-mono
as fontes (títulos e botões, texto normal, números e códigos). Têm uma seção só pra elas, logo abaixo
Detalhe: a home é clarinha por padrão (verde-água) e as outras telas são escuras. Por isso a mesma variável pode ter “cor de partida” diferente em cada uma. Se quiser mudar uma tela só, veja a seção “Mirando numa tela só”. E pra trocar as letras, a seção logo abaixo.

6. Trocar as fontes

O site usa 3 fontes, cada uma com um “papel”. Dá pra trocar todas de uma vez, igualzinho às cores:

:root {
  --font-title: Georgia, serif;
  --font-body: "Trebuchet MS", sans-serif;
  --font-mono: "Courier New", monospace;
}
--font-title
títulos e botões grandes: nome das telas, rótulos, “SALVAR PACKAGE”… (a do site é a Syne)
--font-body
o texto normal: frases, avisos, campos de digitar e botões pequenos (a do site é a DM Sans)
--font-mono
números e códigos: o contador “0/14”, o “0xed218d42”, o nome do arquivo (a do site é a DM Mono)

Não precisa mudar as três: escreva só a que quiser. As que você não escrever ficam do jeito de sempre. Funciona em todas as telas, e os temas prontos também obedecem (se você não escrever nada, cada tema usa as fontes dele).

Que nome eu escrevo?

Fontes do site
Syne, DM Sans e DM Mono. A Home não carrega a DM Mono, então lá ela cai na monoespaçada do aparelho
Fontes do seu aparelho
Georgia, "Times New Roman", "Trebuchet MS", Verdana, "Courier New", "Comic Sans MS". Nome com espaço vai entre aspas
Sempre termine com um tipo genérico
serif (com perninhas), sans-serif (sem perninhas), monospace (máquina de escrever), cursive (de mão) ou system-ui (a do aparelho). Cada aparelho tem as suas fontes (no Android, por exemplo, nem toda fonte de computador existe): se a primeira não existir, o site usa o tipo genérico

Usar uma fonte de fora (Google Fonts, etc.)

O site não aceita @import (é por segurança), mas aceita @font-face com link https://. É como se você “instalasse” a fonte e desse um nome pra ela:

@font-face {
  font-family: "Minha Fonte";
  src: url("https://exemplo.com/minha-fonte.woff2") format("woff2");
  font-display: swap;
}
:root { --font-title: "Minha Fonte", serif; }

O link tem que ser o endereço direto do arquivo da fonte (termina em .woff2, .woff, .ttf ou .otf). Pra pegar uma do Google Fonts:

  1. No navegador, abra https://fonts.googleapis.com/css2?family=Nome+Da+Fonte (troque pelo nome da fonte; espaço vira +).
  2. Vai aparecer um texto cheio de @font-face. Copie tudo.
  3. Cole no CSS personalizado, antes do resto, e use o nome que está em font-family nas variáveis acima.
Dica pra caber nos 20.000 caracteres: o Google manda um bloco pra cada alfabeto (/* cyrillic */, /* latin-ext */…). Apague todos e deixe só o /* latin */: ele já tem todos os acentos do português. No Montador de tema dá pra colar esse texto, que ele confere e monta o CSS pra você.
Não vale: @import, links http:// (sem o “s”) e fonte embutida no próprio CSS (data:). Se a fonte não aparecer, o site usa a de reserva, então nada quebra: confira se o link abre o arquivo, se o nome está igual nos dois lugares e se tem aspas.

Mudar a fonte de um pedaço só

/* só o título da Home */
html[data-page="index"] .title { font-family: Georgia, serif !important; }

/* a letra do Editor: sempre os DOIS juntos */
[data-page="editor"] .edit-textarea,
[data-page="editor"] .ta-backdrop { font-family: "Courier New", monospace !important; }

No Editor, o texto que você vê é desenhado por uma camada por cima da caixa (.ta-backdrop) e a caixa de digitar (.edit-textarea) fica com letra transparente. Por isso fonte e tamanho têm que ser iguais nas duas, senão o texto e o cursor se desencontram. O apelido bonito da janela do perfil (.nick-preview) usa uma letra de mão própria, que não muda com as variáveis: pra trocar, .nick-preview { font-family: ... !important; }.

7. Mirando numa tela só

Cada tela tem um nome secreto. Pra mirar nela, escreva [data-page="nome"] antes do resto:

index
a Home
info
a tela de detalhes do .package (antes de começar a traduzir)
editor
o Editor (onde se traduz)
merge
Mesclar .packages
create
Criar mod do zero
/* botão salvar do editor fica verde, só lá */
[data-page="editor"] .save-btn {
  background: green;
  color: white;
}

/* variável só na Home */
html[data-page="index"] {
  --accent: orange;
}

Dá pra mirar também num tema pronto (os da paleta ), com [data-theme="cult"], por exemplo.

Os temas prontos e como mirar em cada um

Quando um tema pronto está ligado, a tag <html> ganha data-theme="nome". Com o tema Padrão o atributo não existe (então html:not([data-theme]) pega só o Padrão). Os nomes são:

coquette
Coquette: laços, renda e rosa-algodão
vampiro
Vampiro: veludo vinho, morcegos e noite sem fim
slavic
Slavic: pinheiros na névoa, neve caindo e vermelho-sangue
cult
Cult: velas, cruz invertida e sangue seco no subsolo
kamikakushi
Kamikakushi: santuário na névoa, lanternas de pedra e luz divina

Exemplo: pintar o título só no Vampiro, e só na Home:

html[data-theme="vampiro"][data-page="index"] .title {
  color: #ff5c7a !important;
}
Quem ganha? O tema pronto é carregado antes do seu CSS, então o seu vem por cima. Só que os temas usam bastante !important (principalmente na Home e nas janelas). Se o seu CSS não pegou, ponha !important e, se precisar, na frente html[data-theme="nome"] para ficar mais forte que o do tema.
Fundo do tema: o fundo dos temas é pintado no body. Se você trocar o background do body, use !important.

Extras do tema Cult

O Cult é o único que tem peças interativas. Na Home, no rodapé, ele cria um bloco .theme-extras (também com a classe .cult-extras) com dois botões, que só existem enquanto o Cult está ligado:

.cult-btns, .cult-btn
a faixa e os botões apagar as velas / acender as velas e derreter as velas
.cult-moons
o enfeite de luas do bloco
html.cu-out
classe que aparece no <html> quando as velas estão apagadas (a escolha fica salva no aparelho). Use para mudar o visual do "escuro": html.cu-out .title { ... }
html.cu-melt
velas derretidas. É permanente até recarregar a página e esconde os botões; também liga cu-out

A tela da volta do login com Google (só na Home, por 1 ou 2 segundos). É opcional: se você não mexer, ela já usa o fundo e o texto de apoio do seu tema. Se quiser mudar, este pedaço funciona sozinho, é só colar:

#google-cover
a tela cheia que cobre tudo enquanto o login termina (o fundo). A bolinha girando é o #google-cover::before, e a cor dela é a border-top-color. Repare no # em vez do ponto: é um id, não uma classe
#google-cover { background: #1f1433 !important; }
#google-cover::before { border-top-color: hotpink !important; }

Enquanto ela aparece, o html::before e o html::after ficam escondidos, então enfeites do seu tema que usam esses dois não passam por cima dela. No Montador de tema isso é o grupo “Carregamento (volta do Google)”, e ele tem prévia.

11. Truques fáceis

Cantos mais redondos no site todo

:root { --radius: 30px; --radius-sm: 20px; }

Esconder uma coisa

.version { display: none !important; }

Letra maior (bom pra enxergar melhor)

html { zoom: 1.2; }

Aumenta o site todo (letras, botões e espaços) em 20%. Teste 1.1, 1.15, 1.3… até ficar bom. Não adianta mexer no font-size do body: quase tudo no site tem tamanho próprio, então nada muda. Pra aumentar só a letra do Editor, veja a receita lá embaixo.

Trocar o tipo de letra

Use as variáveis da seção 6. Trocar as fontes. Se escrever só font-family no body, só muda o que não tem fonte própria (menos da metade dos textos).

:root { --font-title: Georgia, serif; --font-body: Georgia, serif; }

Imagem de fundo

html[data-page="index"] body {
  background: url("https://exemplo.com/foto.jpg") center / cover fixed !important;
}

Só funcionam links que começam com https://, imagens do próprio site (/img/...) ou imagens embutidas (data:image/...).

Tirar as animações

* { animation: none !important; transition: none !important; }

13. Deu ruim?

“Não mudou nada!”
O site tem várias regras com !important (principalmente a Home e as janelas). Coloque !important antes do ponto e vírgula: color: red !important;. Se tiver um tema pronto ligado, ele também pode ganhar: use !important ou teste com o tema padrão.
“Sumiu quando recarreguei!”
Você deve ter apertado só Aplicar. Aperte Salvar CSS.
“Uma coisa sumiu / o site ficou impossível de usar!”
Calma! Abra o site com ?safe=1 no final do endereço. Isso desliga tema e CSS pessoal só naquela visita, e dá pra ir no perfil corrigir ou apertar Restaurar padrão.
“Disse que o CSS não é permitido”
Por segurança, não vale: @import, javascript:, expression(...), image-set(...) e afins. E em url(...) só https://, /img/ e data:image/ (fonte embutida não vale). Pra fonte de fora use @font-face, não @import: veja a seção “Trocar as fontes”.
“Minha fonte não aparece!”
Confira: o link começa com https:// e abre direto o arquivo da fonte? O nome em font-family do @font-face é igualzinho ao que você escreveu em --font-title (e nome com espaço está entre aspas)? Enquanto não carrega, o site usa a fonte de reserva (o tipo genérico no fim, tipo serif).
“Deu erro de ‘muito grande’”
Passou de 20.000 caracteres. Apague os comentários e as coisas que não usa. Se for fonte do Google, deixe só o bloco /* latin */.
“Escrevi certinho e não funciona”
Confira: tem ; no fim de cada linha? Fechou todas as chaves { }? Uma chave faltando estraga o resto do CSS.
Dica de ouro: mude uma coisa de cada vez e aperte Aplicar. Assim, se algo quebrar, você sabe quem foi.

1. O que é isso?

Imagina o site como uma casa. O CSS é a tinta e o pincel: ele não muda onde ficam as portas, só a cor das paredes, o tamanho dos móveis e esse tipo de coisa. Ou seja: você só muda a aparência, não tem como estragar o site.

O que você escreve vale só pra você (ninguém mais vê) e funciona em todas as telas e em todos os aparelhos em que você entrar na sua conta.

2. Onde eu colo?

  1. Entre na sua conta (o CSS personalizado só aparece pra quem está logado).
  2. Na home, toque na bolinha do perfil (canto de cima).
  3. Abra a seção “CSS personalizado” e cole o seu CSS na caixa.
  4. Aplicar = só uma prévia, pra espiar. Se recarregar a página, ela some.
  5. Salvar CSS = guarda de verdade. Apareceu “CSS salvo!”? Pronto.
  6. Copiar copia o texto. Restaurar padrão apaga tudo e o site volta ao normal.
Importante: Aplicar não é Salvar! Gostou do resultado? Aperte Salvar CSS, senão ele some quando você recarregar.
Máximo de 20.000 caracteres (a caixa mostra a contagem). E cole só CSS de gente em quem você confia.

3. Como o CSS é escrito

Todo pedacinho de CSS é uma frase assim:

QUEM {
  O QUE MUDAR: COMO;
}

Tipo: “o botão grande { cor do texto: rosa; }”. Na linguagem do site:

.btn-new {
  color: hotpink;
}

Dá pra mudar várias coisas de uma vez, uma por linha, e sempre terminando com ponto e vírgula ; (esquecer ele é o erro mais comum!). Tudo que fica entre /* e */ é comentário: o site ignora, é só um bilhetinho seu.

As propriedades mais usadas

color
cor do texto
background
cor (ou degradê, ou imagem) do fundo
border
a bordinha. Ex.: 1px solid pink (grossura, tipo, cor)
border-radius
quão redondo são os cantos. 0 = quadrado, 999px = pílula
font-size
tamanho da letra. Ex.: 18px
font-family
o tipo de letra. Ex.: Georgia, serif
opacity
transparência: 1 normal, 0.5 meio apagado, 0 invisível
display: none
esconde a coisa (como se ela nunca tivesse existido)
padding e margin
espaço por dentro e por fora da coisa

4. Cores

Dá pra escrever a cor de três jeitos (todos funcionam em qualquer lugar):

Por nome
red, hotpink, gold, teal…
Por código
#ff4fa3. Pesquise “seletor de cor” no Google, escolha a cor e copie o código.
Com transparência
rgba(255, 79, 163, 0.3): os três primeiros são vermelho, verde e azul (0 a 255); o último é a transparência (0 a 1).

Degradê (duas cores se misturando): background: linear-gradient(135deg, #ff4fa3, #35e0ff);

5. Variáveis mágicas (o jeito mais fácil!)

O site tem uns “botões de cor” escondidos chamados variáveis. Mudou uma, mudou o site inteiro de uma vez. É o truque mais poderoso, então comece por aqui:

:root {
  --accent: #ff4fa3;
}

Isso troca a cor de destaque em todas as telas. As variáveis são:

--bg
cor de fundo das telas
--surface
fundo de cartões, caixas e botões
--surface2
fundo de caixas mais “fundas” (campos, linhas)
--surface3
fundo de áreas extras (tela Criar)
--border, --border2, --border3
cores das bordinhas (da mais fraca à mais forte)
--accent
cor de destaque: títulos, ícones, números, links
--accent-dim
destaque mais escuro (botões, quando você aperta)
--accent-faint
destaque bem clarinho (fundos suaves)
--text
cor do texto principal
--text-muted
cor do texto de apoio (as letrinhas menores)
--text-dim
cor do texto bem discreto
--danger
vermelho de erro e de apagar
--radius, --radius-sm, --radius-xs
quão redondos são os cantos (grande, médio, pequeno)
Detalhe: a home é clarinha por padrão (verde-água) e as outras telas são escuras. Por isso a mesma variável pode ter “cor de partida” diferente em cada uma. Se quiser mudar uma tela só, veja a próxima seção.

6. Mirando numa tela só

Cada tela tem um nome secreto. Pra mirar nela, escreva [data-page="nome"] antes do resto:

index
a Home
info
a tela de detalhes do .package (antes de começar a traduzir)
editor
o Editor (onde se traduz)
merge
Mesclar .packages
create
Criar mod do zero
/* botão salvar do editor fica verde, só lá */
[data-page="editor"] .save-btn {
  background: green;
  color: white;
}

/* variável só na Home */
html[data-page="index"] {
  --accent: orange;
}

Dá pra mirar também num tema pronto (os da paleta ), com [data-theme="cult"], por exemplo.

9. Info, Editor, Mesclar e Criar

Agora o passeio guiado: vamos descendo cada tela de cima pra baixo, dizendo o nome de cada pedaço. Todas essas telas têm em comum: .topbar (barra de cima), .back-btn (a setinha ←), .topbar-title (o título ao lado dela), .section-label (os rótulos cinzinhas tipo “DETALHES”) e .separator (a linha que separa). Pra mudar só uma tela, comece com [data-page="..."].

Info [data-page="info"]

É a tela que aparece depois de escolher um .package, antes de começar a traduzir.

Topo
.topbar-title é o nome do arquivo (“DEVIOUSDESIRES.PACKAGE”).
“DETALHES”
é um .section-label. As três caixinhas lado a lado ficam dentro de .three-cols, e cada uma é um .info-block, com o nome em cima (.block-label: “INSTANCE”, “GROUP”) e o valor embaixo (.block-value).
Caixinha do meio
“LÍNGUA DESTINO” tem o botão .lang-btn (“POR_BR ▾”) e a dica .lang-hint (“toque p/ escolher”). Ao tocar abre a gaveta .lang-sheet, com as opções em .lang-option.
Embaixo
o botão .start-btn (“COMEÇAR →”).
[data-page="info"] .info-block { background: #2a1a45; border-radius: 24px; }
[data-page="info"] .start-btn { background: hotpink; color: #fff; }

Editor [data-page="editor"]

Barra de cima (da esquerda pra direita):

.topbar-title e .topbar-sub
“Editor” e o “POR_BR → POR_BR” embaixo dele
.undo-btn
desfazer e refazer (↶ ↷)
.focus-toggle-btn
a bolinha do olho (modo foco). Ligada ela ganha .focus-on
.timer-badge e .count-badge
o relógio “0:02” e o “0/14” (quantas já foram traduzidas)
.save-progress-btn
o ↻ e o ✓ do canto

Busca e filtros: .search-input (“Buscar por key…”), .filter-toggle-row (“Filtrar por ▼”), .filter-bar (a faixa toda) e .col-header (“ORIGINAL” e “TRADUÇÃO”).

Cada linha é um .string-row:

.row-num e .key-hex
o número (1, 2, 3…) e o código (“0xed218d42”) acima dela
.original-text
a caixa do texto original (em itálico), à esquerda. O texto em si é .original-text-inner, e o botãozinho de copiar dentro dela é o .copy-btn
.edit-textarea
a caixa onde você escreve a tradução, à direita
.fav-btn
a estrelinha (acesa = .fav-btn.active)
.expand-arrow-btn
a setinha ▾ que aumenta a caixa
.kebab-btn
os três pontinhos ⋮ (o menu que abre é o .kebab-menu)
.ph e .ph-unclosed
os trechos com { }. Quando a chave fica aberta (sem fechar), o texto fica amarelo; é o .ph-unclosed

Barra de baixo (.bottom-bar): “Nome:” + .filename-input + “.package”; a linha “ Alterar instância base” (.instance-toggle-row); e os botões .import-btn (⇄ e ◈), .json-mode-btn (JSON) e .save-btn (“SALVAR PACKAGE”).

10. Truques fáceis

Cantos mais redondos no site todo

:root { --radius: 30px; --radius-sm: 20px; }

Esconder uma coisa

.version { display: none !important; }

Letra maior (bom pra enxergar melhor)

body { font-size: 18px; }

Trocar o tipo de letra

O site já traz Syne, DM Sans e DM Mono. Dá pra usar elas, ou as do seu aparelho, como Georgia ou "Courier New".

body { font-family: Georgia, serif !important; }

Imagem de fundo

html[data-page="index"] body {
  background: url("https://exemplo.com/foto.jpg") center / cover fixed !important;
}

Só funcionam links que começam com https://, imagens do próprio site (/img/...) ou imagens embutidas (data:image/...).

Tirar as animações

* { animation: none !important; transition: none !important; }

12. Deu ruim?

“Não mudou nada!”
O site tem várias regras com !important (principalmente a Home e as janelas). Coloque !important antes do ponto e vírgula: color: red !important;. Se tiver um tema pronto ligado, ele também pode ganhar: use !important ou teste com o tema padrão.
“Sumiu quando recarreguei!”
Você deve ter apertado só Aplicar. Aperte Salvar CSS.
“Uma coisa sumiu / o site ficou impossível de usar!”
Calma! Abra o site com ?safe=1 no final do endereço. Isso desliga tema e CSS pessoal só naquela visita, e dá pra ir no perfil corrigir ou apertar Restaurar padrão.
“Disse que o CSS não é permitido”
Por segurança, não vale: @import, javascript:, expression(...), image-set(...) e afins. E em url(...) só https://, /img/ e data:image/.
“Deu erro de ‘muito grande’”
Passou de 20.000 caracteres. Apague os comentários e as coisas que não usa.
“Escrevi certinho e não funciona”
Confira: tem ; no fim de cada linha? Fechou todas as chaves { }? Uma chave faltando estraga o resto do CSS.
Dica de ouro: mude uma coisa de cada vez e aperte Aplicar. Assim, se algo quebrar, você sabe quem foi.
